# MAX-бот

Бот в мессенджере MAX — порт Telegram-бота: те же сценарии (главный, рефералка, уведомления, персональные ссылки менеджеров), адаптированные под ограничения платформы.

## Отличия от Telegram

- В MAX нет кнопки «Отправить номер» — бот просит ввести номер текстом: «Введи номер в формате +7xxxxxxxxxx… Отправляя номер, вы даёте согласие на обработку персональных данных.»
- Ссылки в сообщениях — обычным текстом (MAX не рендерит HTML-разметку <a>).
- Источник лида в Битрикс24: SOURCE_ID=9995761294, «Источник New»=2262 («MAX бот») вместо 22|TELEGRAM / 1840.
- Кнопка «Регистрация» ведёт на https://referral.drive16.online/go/max-ref (в ТГ — /go/tg-ref), чтобы разделять канал прихода.
- Уведомление о реферале отправляется через notification_contact в другой бот — сотрудник получает его там, где сидит.
- Рассылка в MAX передаёт лид через вебхук Albato, а в ТГ — напрямую в Битрикс24 (batch.json).

Схемы, совпадающие с Telegram, см. в [../telegram](../telegram). Отличающаяся схема рассылки — [mailing.md](mailing.md).
