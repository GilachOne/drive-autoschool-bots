> **Архив.** Прежняя версия реферальной программы. Сейчас она перенесена из ботов в веб-кабинет реферала; схема сохранена, чтобы показать, как программа работала внутри мессенджера.

# Персональная ссылка менеджера (шаблон)

Для каждого менеджера — свой стартовый сценарий: фиксирует ответственного (`assigned`) и запускает рефералку. Так лиды по ссылке менеджера сразу падали на него в CRM.

## Схема

```mermaid
flowchart TD
  s1["🧮 Переменные<br/>МЕНЕДЖЕР"]
  s2["↪ Переход в сценарий<br/>Рефералка"]
  s3["▶ Старт"]
  s1 --> s2
  s3 --> s1
```

## Переменные

`assigned`

Полная выгрузка блоков — в соседнем `.json` (секреты заменены плейсхолдерами).
